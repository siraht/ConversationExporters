Acceptance contract

Export every conversation the connected provider account exposes, across all supported organizations/workspaces, normal history, archived history and projects where exposed. Preserve complete retrievable message trees, settings, attachments and generated assets. Never restrict by date. Preserve previously downloaded records. Discover new chats and revisit changed chats on subsequent syncs without duplicating stable identities.

Inventory completeness, content completeness, archive freshness and successful replication are separate facts. A downloaded/discovered ratio alone cannot prove discovery completeness. Missing scopes, malformed responses, truncated pagination, expired assets and inaccessible records must remain explicit failures or limitations; they must never become a green “everything” claim. Deleted, temporary, expired or otherwise unexposed provider content cannot be reconstructed, and must not be promised.

Implementation sequence and cost controls

  1. Fix silent data loss and false success first, in independent provider and orchestration changes.
  2. Test concrete failure cases with synthetic fixtures. No private exports, tokens, chat titles or account data enter Git.
  3. Integrate status reporting and create final builds. Re-run tests only after relevant changes or actual failures.
  4. Review this matrix at integration and handoff. Every open item must have a specific limitation or next action; no new framework, database, dependency or telemetry service is needed.
  5. Leave provider endpoint uncertainty to explicit live evidence instead of inventing undocumented API behavior. User manually verifies the final extension.

Decisions and lessons

  • A safety limit is acceptable only if reaching it produces an incomplete result; returning a partial list as success is not acceptable.
  • A provider's terminal response is evidence of enumeration completion, not independent proof that its private API exposes every product feature.
  • Missing update timestamps are unknown freshness, not evidence that a chat is unchanged.
