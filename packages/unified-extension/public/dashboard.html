REFERENCE

How to use it

The short version: stay signed in, refresh provider tabs after extension updates, then sync.

1

Open signed-in tabs

Keep each provider open in this browser. The extension uses the session already in that tab.

2

Capture conversations

Use Sync now beside any provider, or Sync all providers to update every available archive.

3

Keep a portable copy

Download a ZIP, or configure replication to copy changed archive files to storage you control.

What does AI Studio need before its first sync?

After installing or reloading the extension, refresh AI Studio History and open one saved prompt once. This initializes the authenticated inventory and detail requests used by sync.

Where do credentials and conversations go?

Provider credentials remain inside signed-in provider tabs. VPS credentials remain in extension-local storage. Conversations stay in the browser archive unless you download them or enable a replication target.

What does a ChatGPT or Grok sync include?

The same complete capture engines now run here: inventories, projects and workspaces, conversation bodies, referenced assets, resumable completion markers, and validation reports.

Do repeated syncs create duplicates?

No. Provider records use stable identities; subsequent syncs retain or replace the existing record when content changes.
