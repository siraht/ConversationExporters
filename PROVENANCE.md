# Provenance

The Grok package was imported from `siraht/GrokExporter` tag `v0.1.0`, accepted at commit `3d364b5`. The ChatGPT package was imported from `siraht/ChatGPTExporter` tag `v0.1.6`, accepted at commit `c5618b3`.

Both standalone repositories are MIT licensed. Their original file-level attribution and Git history remain available in the source repositories and in the subtree-import commits here. Common modules are extracted only after byte-level or compatibility tests demonstrate equivalent behavior; provider-specific code remains in its originating package.

The original package documentation and upstream research matrices remain under `packages/grok-exporter/docs` and `packages/chatgpt-exporter/docs`. Those records identify the pinned third-party revisions that informed endpoint research and distinguish adapted code from rejected approaches.

The consolidated repository preserves each accepted manifest byte-for-byte at import, pins deterministic synthetic archive hashes derived from the standalone tags, and continues to emit independent provider releases. The standalone repositories and tags remain the upgrade and regression baselines; consolidation does not claim ownership of or rewrite private archive data.
