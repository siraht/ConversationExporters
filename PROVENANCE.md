# Provenance

The Grok package was imported from `siraht/GrokExporter` tag `v0.1.0`, accepted at commit `3d364b5`. The ChatGPT package was imported from `siraht/ChatGPTExporter` tag `v0.1.6`, accepted at commit `c5618b3`.

Both standalone repositories are MIT licensed. Their original file-level attribution and Git history remain available in the source repositories and in the subtree-import commits here. Common modules are extracted only after byte-level or compatibility tests demonstrate equivalent behavior; provider-specific code remains in its originating package.
